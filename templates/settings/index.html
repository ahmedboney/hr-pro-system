الأمان - مفتاح API للأجهزة

أجهزة البصمة تسجل الحضور عبر واجهة API محمية بمفتاح سري. مرر المفتاح مع كل طلب في الهيدر X-API-Key، وقم بتجديده إذا خرج عن حوزتك.

مثال الطلب: curl -X POST http://127.0.0.1:8080/api/fingerprint/punch
  -H "X-API-Key: {{ setting('api_key') or 'HR-XXXX' }}"
  -H "Content-Type: application/json"
  -d "{\"fingerprint_id\":\"1001\",\"timestamp\":\"{{ today.strftime('%Y-%m-%d') }} 09:00:00\"}"
